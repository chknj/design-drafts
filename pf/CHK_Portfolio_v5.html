My approach↓

Design.
And beyond.

여러 브랜드의 디자인을 함께 운영하려면 좋은 결과물과 함께 일하는 기준이 필요합니다. 담당을 나누고, 제작 표준을 세우고, 반복되는 일은 자동화합니다.

AI는 공식몰 구현의 문제를 해결하는 도구이자, 새로운 표현을 직접 만들어보는 실험의 도구로 활용합니다.

브랜드는 각자의 모습으로.
팀은 명확한 기준으로.
반복은 더 간단한 방식으로.

How I work

업무 배분부터
오픈 이후의 운영까지.

A /

역할을 명확하게.

브랜드별 담당과 기능별 업무를 배분합니다. 공식몰은 직접 구축하고, 유지보수는 담당자에게 이관해 구축과 운영을 연결합니다.

B /

기준은 함께 쓰도록.

상품 정보 중심의 PDP 표준과 브랜드 가이드를 정리합니다. 촬영팀·상품MD·운영지원팀과 제작 및 전달 방식을 맞춥니다.

C /

반복은 도구에 맡기도록.

표준을 실제 제작 도구로 구현합니다. 텍스트 이미지화, 이미지 순서 배치, 등록 코드 작성처럼 반복되는 단계를 자동화합니다.

Applied automation / PDP builder

From standard
to system.

상세페이지 표준안을 실제 제작에 적용하는 자동화 빌더를 만들었습니다. 엑셀과 이미지 폴더를 넣으면, 규격에 맞는 이미지와 등록용 파일을 생성합니다.

디자이너가 반복 수작업에 쓰던 시간을 기획과 연출에 쓸 수 있도록 만드는 작업입니다.

01 / Input

엑셀과 이미지.

상품 텍스트와 이미지코드로
정리된 이미지 폴더를 입력합니다.

02 / Build

규격에 맞게 조립.

텍스트를 이미지로 만들고,
표준 순서에 맞춰 콘텐츠를 배치합니다.

03 / Output

등록까지 연결.

이미지 ZIP, HTML 코드와
정렬 코드 스프레드시트를 생성합니다.

In-house.

기획부터 제작·운영까지

PDP·공식몰·마케팅 디자인을 외주 제작 없이 팀 내에서 수행했습니다.

수치는 본인 업무 경험에 따른 자체 평가입니다. 생산성 수치의 산정 기간·방식은 별도 정리가 필요하며, 자동화 빌더 단독의 실측 효과와는 구분합니다. 인하우스 범위는 디자인 제작 업무 기준입니다.
